# DT–TL–BIM Bridge SHM Evidence Dataset

This repository contains the evidence-charting dataset supporting the systematic scoping review:

**A Systematic Scoping Review of Digital Twin, Transfer Learning, and BIM Integration in Bridge Structural Health Monitoring**

## Dataset

The main dataset is provided in:

`Supplementary_Table_S1_Evidence Dataset.xlsx`

The workbook contains study-level information used in the review, including:

- bibliographic information and DOI links;
- database/indexing coverage;
- study category and bridge/application context;
- sensing modality;
- Digital Twin role;
- Transfer Learning/domain-adaptation strategy;
- BIM integration level;
- validation approach;
- lifecycle phase;
- evidence basis and applicability rationale;
- domain-shift coding and supporting evidence;
- post-modification/retrofit/structural-state-transfer coding;
- real operational bridge-data coding; and
- DT–TL–BIM integration coding.

The workbook also includes the coding criteria used for evidence classification and sensitivity analysis.

## Evidence base

The dataset contains 77 included studies and distinguishes between bridge-specific evidence and transferable non-bridge methodological evidence.
